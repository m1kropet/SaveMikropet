# Защити микропета от ковтопа

2D Tower Defense для браузера и вертикального виджета Twitch (9:16). Чистый JavaScript и Canvas 2D, без сборки и без внешних библиотек.

## Запуск

- Проще всего — вместе с игровым сервером: `node server/server.js` → `http://localhost:8787`. Сервер раздаёт игру и сам подключает мультиплеер.
- Без сервера (только одиночка, локальная команда и бот): `python3 -m http.server` → `http://localhost:8000`.
- Twitch-оверлей: источник «Браузер» в OBS, 1080×1920, URL страницы игры.
- Тесты: `node test/logic.test.js` (логика), `node test/balance.js hard` (баланс прогонами бота).

## Вход через Twitch

1. Зарегистрируйте приложение на https://dev.twitch.tv/console/apps.
2. В поле OAuth Redirect URL укажите точный адрес страницы игры (https, без `#`), например `https://example.org/mikropet/`.
3. Впишите Client ID в `js/config.js` → `twitchClientId`.
4. Для стрима можно включить `requireTwitch: true` — играть получится только после входа.

Игра использует implicit flow: токен приходит в адресе, проверяется через `id.twitch.tv/oauth2/validate`, профиль берётся из Helix `/users`. Токен хранится только в sessionStorage. Сервер (`server/server.js`) проверяет токен заново и засчитывает рейтинг только подтверждённым игрокам. Внутри iframe (в том числе на странице Claude) Twitch не показывает окно входа — откройте игру отдельной вкладкой на своём домене.


## Вход через Google

1. Откройте https://console.cloud.google.com → создайте проект → **APIs & Services → OAuth consent screen**: тип External, укажите название игры и свою почту. Пока приложение в режиме Testing, войти смогут только добавленные тестовые пользователи; чтобы входили все — нажмите **Publish app** (для scope `openid email profile` проверка Google не нужна).
2. **APIs & Services → Credentials → Create credentials → OAuth client ID**, тип **Web application**.
3. **Authorized JavaScript origins:** адрес игры без пути, например `https://savemikropet.kolyahollyday134.workers.dev`.
   **Authorized redirect URIs:** адрес страницы игры со слешем в конце, например `https://savemikropet.kolyahollyday134.workers.dev/`.
4. Скопируйте Client ID (`…apps.googleusercontent.com`) и укажите его:
   - Cloudflare: Workers & Pages → savemikropet → Settings → Variables and Secrets → добавить `GOOGLE_CLIENT_ID` (или раскомментировать строку в `[vars]` файла `wrangler.toml`);
   - Node-сервер: переменная окружения `GOOGLE_CLIENT_ID`.

Используется OpenID implicit flow: Google возвращает `id_token` в адресе, игра сверяет client_id, срок, nonce и подтверждённость почты, сервер проверяет токен заново через `oauth2.googleapis.com/tokeninfo`. Секретный ключ клиента не нужен. Ник в игре не меняется, почту видит только сам игрок. Вошедшие через Google попадают в общий рейтинг так же, как через Twitch; `requireTwitch: true` пускает в игру после входа любым из двух способов.

## Игровой сервер (мультиплеер)

`server/server.js` — один процесс на Node.js 18+ без npm-зависимостей: раздаёт файлы игры и принимает WebSocket на `/ws`.

- **Публичные лобби:** во вкладке «Команда» есть лобби на 2, 3 и 4 игрока — без создания комнаты. Видно, сколько игроков уже ждёт. Когда лобби заполняется, через 5 секунд все попадают в совместную игру (карта случайная, сложность «Нормально»). Если кто-то выходит во время отсчёта, отсчёт отменяется.
- **Команда онлайн:** хост создаёт комнату и получает код `KV-XXXX`, друзья входят по коду (2–4 игрока). Хост выбирает карту, сложность и автозапуск волн, матч начинается, когда все готовы. Деньги общие, у каждого свой цвет башен, строить можно героями из своего отряда.
- **Дуэль онлайн:** случайный подбор (ближайший по уровню из очереди) или вызов друга по коду. У обоих один seed, волны общие, карта соперника доступна для просмотра. Выход или обрыв связи — поражение.
- **Честность:** симуляция идёт только на сервере (тот же `js/sim.js`), клиент присылает команды. Покупки проверяются и списываются атомарно, повторы команд отсекаются, частота сообщений ограничена (30/с).
- **Рейтинг:** сервер засчитывает только игроков, вошедших через Twitch (токен проверяется сервером). Рейтинг хранится в памяти процесса и сбрасывается при перезапуске — для постоянного хранения подключите базу данных в функции `record()`.

### Ссылка через Cloudflare

**Вариант 1. Постоянная ссылка — Cloudflare Workers (бесплатный тариф).** Игра и сервер работают в облаке Cloudflare, компьютер можно выключить.

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. Установите Node.js 18+ и в папке проекта выполните:
   ```bash
   npx wrangler login
   npx wrangler deploy
   ```
3. Wrangler выдаст ссылку вида `https://savemikropet.<ваш-поддомен>.workers.dev` — по ней можно играть с любого устройства, онлайн-режимы подключатся автоматически.

Устройство: `worker/worker.js` раздаёт файлы игры, а все WebSocket-подключения ведёт в один Durable Object `GameHub` с тем же хабом (`server/hub.js`), что и Node-сервер. Twitch: добавьте `TWITCH_CLIENT_ID` в `[vars]` файла `wrangler.toml`, а Redirect URL в приложении Twitch укажите равным выданной ссылке. Ограничения бесплатного тарифа Durable Objects — на сайте Cloudflare; для небольшой компании игроков их хватает с запасом.

**Вариант 2. Быстрая временная ссылка — Cloudflare Tunnel.** Сервер работает на вашем компьютере, Cloudflare даёт к нему публичный адрес.

- Windows: установите `cloudflared` (`winget install --id Cloudflare.cloudflared`) и запустите `start-online.bat`.
- macOS/Linux: установите `cloudflared` и запустите `./start-online.sh`.

В окне появится ссылка `https://….trycloudflare.com`. Она работает, пока открыто окно и включён компьютер; при каждом запуске ссылка новая.

### Развёртывание

Нужен хостинг с поддержкой WebSocket и HTTPS (для Twitch обязательно): VPS, Render, Railway, Fly.io и т. п.

```bash
# VPS с Node.js 18+
PORT=8787 TWITCH_CLIENT_ID=ваш_id node server/server.js
# или Docker
docker build -t mikropet . && docker run -p 8787:8787 -e TWITCH_CLIENT_ID=ваш_id mikropet
```

Переменные: `PORT`, `TWITCH_CLIENT_ID`, `REQUIRE_TWITCH=1` (играть онлайн только после входа). Проверка работы: `GET /healthz`. За nginx пробросьте заголовки `Upgrade`/`Connection` для `/ws`. Если игра размещена отдельно от сервера, укажите адрес в `js/config.js`: `serverUrl: 'wss://ваш-домен/ws'`.

Тесты сервера: `node test/server.test.js` (два клиента: комната, гонка покупок, дуэль, отключение).

## Обновление: экономика, Свинка, теги, голосования

- **Башни переименованы:** Бластер, Диномайк, Морозилка, Реалганер, Громовержец, Свинка. Цены улучшений заданы в `js/data.js`.
- **Свинка** не атакует. Доход 30 монет за волну хозяину. Верхняя ветка: лечение микропета после волны, +жизни, щит, блокирующий дошедших сущностей. Нижняя: больше дохода и проценты от монет.
- **Морозилка 0/5** получает «заморозку боссов»: каждое попадание охлаждает босса, и он ненадолго замерзает.
- **Команда:** у каждого игрока свои деньги. Награды за врагов и волны делятся поровну, доход Свинки идёт хозяину. Улучшать и продавать можно только свои башни.
- **Пропуск ожидания волны:** 1–2 игрока — нужен 1 голос, 3–4 игрока — 2 голоса.
- **Голосование за сложность** в онлайн-команде: 30 секунд (или пока не проголосуют все). При равенстве — случайная из отмеченных. Бесконечный режим доступен, если он открыт хотя бы у одного игрока.
- **Теги игроков `#XXX`:** случайные, не меняются. Сервер хранит их и гарантирует уникальность; когда трёхсимвольные теги закончатся, выдаются четырёхсимвольные. Поиск друзей — по тегу.
- **Коды комнат** — 4 латинские буквы или цифры, без приставки.
- **Настройки игры** (автозапуск волн, скорость, звук, графика) — в меню паузы. В онлайн-матче это меню не останавливает игру.
- **Хранилище:** теги и рейтинг сохраняются в `data/store.json` (Node) или в хранилище Durable Object (Cloudflare).

## Механики

- Башни ставятся где угодно, кроме дороги сущностей, препятствий и вплотную к другим башням.
- Препятствия (шкафы, колонны, валуны, кристаллы и т. д.) занимают место и закрывают обзор. Башня поворачивается к врагу за препятствием, но не стреляет, пока он снова не окажется в зоне видимости; снаряды тоже разбиваются о препятствия. Высокие препятствия закрывают всех, низкие — только наземных. Каждые 4 волны появляются новые препятствия.
- Дуэль: бот подбирается под уровень игрока (±2) и берёт тот же набор героев. Волны общие: следующая начинается у обоих, только когда оба отбили текущую. Кнопка «Карта соперника» показывает его поле и прокачку башен.
- Прокачка: две ветки по 5 уровней, уровни 1–2 доступны в обеих ветках всегда, выше 2-го прокачивается только одна ветка. Выбранное улучшение не меняется при наведении на другие.
